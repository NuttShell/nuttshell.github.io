Tools

Small utilities that solve one problem each — Python packaging, font internals, and a Xiaomi cloud token grabber. Everything here is source-available on GitHub.

  • Python embed installer

    Self-contained embeddable Python installer — console or GUI, no system install.

  • Xiaomi-cloud-tokens-extractor

    Retrieves Xiaomi cloud tokens and BLE encryption keys for every device on your account.

  • Font-NameTablecheck visibility

    Reads and rebuilds OpenType/TrueType name table records.

  • CFF Font Vertical Metricscheck visibility

    Vertical metrics fix for CFF fonts on Android.

  • TrueType 2 OpenType convertercheck visibility

    Converts TTF fonts to OTF.
